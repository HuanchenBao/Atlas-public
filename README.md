# Atlas

A visual notebook for ideas, local dictation and linked Codex conversations.

**[Download Atlas for Apple Silicon](https://github.com/HuanchenBao/Atlas-public/releases/latest)** · macOS 14 or later

Open the DMG, drag Atlas to Applications, then launch it from Applications. The released app and installer are Developer ID signed and notarized by Apple. Verify the download against the release’s `SHA256SUMS.txt`.

See [Atlas 0.24 release notes](RELEASE-NOTES.md) for setup, speech-model downloads, optional Hugging Face formatting, Calendar permissions, and Codex account/source coverage and live-status limitations.

**Public Dropbox connection is pending.** The current provider registration is Development / Only you; this release does not promise Dropbox access for other users.

This public repository contains installation documentation and checksums. Application implementation and private development history are not published here. Third-party notices are included in the app.
